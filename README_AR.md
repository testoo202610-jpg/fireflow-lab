# FireFlow Lab — مختبر شبكات مكافحة الحريق

تطبيق فعلي يعمل محليًا في المتصفح بالعربية وRTL أو الإنجليزية. يحسب الضغوط
والتدفقات باستخدام **OWA EPANET 2.2** عبر **epanet-js 0.9.0 وWebAssembly** داخل
Web Worker. لا يحتاج الاستخدام الأساسي إلى خادم مدفوع أو مفتاح API.

[English](README.md) · [تفاصيل النموذج الهندسي](docs/ENGINEERING.md) · [التحقق الفعلي](docs/VERIFICATION.md) · [النشر على Cloudflare](docs/CLOUDFLARE.md)

## التشغيل

يلزم Node.js 24 أو أحدث وnpm. افتح مجلد المشروع:

```sh
npm install
npm run dev
```

افتح `http://localhost:5173`. العربية افتراضية. زر **EN** يبدّل اللغة.
عملية التثبيت تنسخ ملف المحرك المثبت إلى `public/epanet-2.2.wasm`؛ يُحمّل
من أصل التطبيق نفسه. بعد تثبيت الأصول يعمل الحساب دون خدمة ذكاء اصطناعي.

```sh
npm run typecheck
npm run lint
npm run test
npx playwright install --with-deps chromium
npm run test:e2e
npm run build
npm run preview
```

## الاستخدام

1. **فتح مشروع** يعرض المشاريع التعليمية والمحفوظة. في الهاتف: **القائمة → فتح مشروع**.
2. اسحب عنصرًا أو انقر عليه لإضافته. المضخات والمحابس تنشئ عقدتي مدخل ومخرج
   ووصلة بينهما؛ صل نقاط العقد بمواسير. اختر نوع الوصلة الجديدة من شريط المحرر.
3. انقر عقدة أو تسمية وصلة لتحرير الخصائص. الطول والارتفاع بيانات مستقلة عن موضع الرسم.
4. أدخل منحنى المضخة بصيغة `تدفق L/s, رأس m`، سطر لكل نقطة. البيانات المقننة
   تعريفية، والمنحنى هو الذي يحدد الأداء. المنحنيات الافتراضية تعليمية فقط.
5. غيّر PRV أو حالات المضخات والمحابس، ثم اضغط **تشغيل المحاكاة**.
6. ستظهر قراءات المحرك في الرسم والجداول والرسوم البيانية. النتائج السابقة
   تُبطل فور تغيير المدخلات الهيدروليكية. فشل الحساب لا يعرض أرقامًا قديمة.
7. كل تشغيل يحتفظ بنسخة المدخلات والنتيجة. من **السيناريوهات** احفظ أسماء
   مخصصة أو قارن حالتين. زر **حساب الثابت والمتبقي** يغيّر الطلب وحده بين الحالتين.
8. الحفظ التلقائي في IndexedDB بعد 750 ms، واستعادة آخر مشروع عند إعادة الفتح.
   تصدير JSON مفيد للنسخ الاحتياطي؛ التخزين ليس مزامنة سحابية.

يدعم المحرر النسخ والحذف والاختيار المتعدد مع Shift والتراجع/الإعادة والتكبير
والتحريك واحتواء الشبكة. Ctrl/Cmd+Z للتراجع. يتوفر وضع داكن وفاتح.

## مشروع High-Rise والقياسات الفعلية

اختر **فتح مشروع → High-Rise Building → تشغيل المحاكاة**. يتضمن خمسة أدوار
رئيسية وخمسة مستويات إضافية، وصاعدًا ومصدرًا ومضخة وPRV وZCV.

حدد العقدة لإدخال ارتفاعها وطلبها و**القياس الميداني المرجعي bar**. حدد
المواسير لإدخال أطوالها وأقطارها الداخلية وخشونتها، والمضخة لإدخال منحنى
المصنّع الفعلي. من **السيناريوهات** أو **التقرير** راجع Model − Field.
القراءتان 11.5 و6.6 bar مرجعان تدريبيان فقط؛ لا يُفرضان على المحرك، ولا يعنيان
أن الشبكة معايرة. يمكن إضافة قياسات أخرى من خصائص العقد.

## التقارير والتصدير

تصدير المشروع JSON، وتصدير شبكة EPANET بصيغة INP، ونتائج CSV. افتح
**التقرير → طباعة / حفظ PDF** لتقرير بمدخلات الحساب، والنتائج، وحدود التنبيه،
والتحذيرات والافتراضات وحالة الحل ونسخة المحرك.

## الملفات الرئيسية

- `src/hydraulic/`: المحرك الحقيقي، محول INP، التحقق والتحويلات.
- `src/features/editor/`: محرر React Flow وخصائص العناصر.
- `src/features/simulation/`: خدمة Worker ووقت الانتظار وتحميل WASM.
- `src/features/scenarios/` و`results/` و`reports/`: المقارنة والجداول والرسوم والتقارير.
- `src/storage/`: IndexedDB والتحقق من JSON ونسخة المخطط v1.
- `src/demo/`: مدخلات المشاريع التعليمية دون نتائج محسوبة مختلقة.
- `src/tests/` و`e2e/`: اختبارات عددية ووحدات وتخزين وواجهة ومتصفح فعلية.
- `.github/workflows/`: CI ونشر GitHub Pages جاهزان.

## الحدود الهندسية

محاكاة الحالة المستقرة فقط؛ لا يوجد EPS أو Water Hammer أو استيراد INP أو
معايرة آلية. محابس Gate وButterfly وIsolation وZCV ممثلة بمواسير ومعامل K
وحالة فتح/غلق؛ ليست نماذج لمنحنيات فتح المصنّع. القياسات تقرأ نتائج العقد
والوَصلات. نموذج PDA الافتراضي يقلل الطلب عند نقص الضغط؛ DDA يفرض الطلب
حتى عند الضغوط السالبة. تبديل الاحتكاك يعيد الخشونة إلى قيمة تعليمية افتراضية
مع إشعار، ويجب إدخال قيمة المادة الفعلية بعدها. حدود الضغط يختارها المستخدم.

**هذا البرنامج أداة تعليمية وتحليلية. لا تُستخدم مخرجاته وحدها لاعتماد تصميم
أو تعديل أو تشغيل نظام مكافحة حريق حقيقي. يلزم التحقق من المدخلات والمعايير
المعمول بها ومراجعة مهندس مختص.** لا تُدّعى مطابقة NFPA 13 أو NFPA 20 أو NFPA 25.

للنشر الحالي على Cloudflare راجع [دليل النشر](docs/CLOUDFLARE.md).

https://fireflow-lab.frosted-editor.workers.dev/
النشر الدائم ورفع المصدر إلى GitHub ما زالا يحتاجان اتصال الحسابين.
